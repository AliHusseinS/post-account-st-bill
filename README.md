# نظام متابعة وتسديد أجور طلبة الدراسات العليا والربط المحاسبي

نظام إلكتروني متكامل باللغة العربية لإدارة وتدقيق تسديدات طلبة الدراسات العليا مع الفصل التام للصلاحيات بين **قسم الدراسات العليا / المتابعة** و**قسم الحسابات والتدقيق المالي**، مع دعم المزامنة مع **Google Sheets** وتصدير تقارير وبراءات ذمة بصيغة **PDF** و **Excel**.

---

## 👥 الصلاحيات وحسابات الدخول

النظام مزود بصلاحيتين منفصلتين وفق متطلبات العمل الجامعي:

| الصلاحية / القسم | اسم المستخدم | كلمة المرور | المهام والمسؤوليات |
| :--- | :---: | :---: | :--- |
| **قسم الدراسات العليا / المتابعة** | `postgrad` | `123` | • إدخال بيانات الطالب الأولية (الاسم الرباعي، النفقة، القسم، نوع الدراسة، التخصص، سنة القبول، سنة التخرج)<br>• استعراض كافة السجلات وحالة التسديد وصور الوصولات<br>• تنزيل استمارات براءة الذمة الفردية وكشوفات التسديد الشاملة كـ PDF |
| **قسم الحسابات** | `accounts` | `123` | • استعراض الطلبة المسجلين من قبل الدراسات العليا (الحقول الأكاديمية للقراءة فقط)<br>• رفع صورة وصل الدفع المالي مع خاصية التكبير والمعاينة<br>• إدخال المبلغ المسدد وتاريخ التسديد واسم المدقق |

> **ملاحظة:** تتوفر أيضاً أزرار "دخول سريع بنقرة واحدة" في شاشة الدخول لتسهيل التجربة والتنقل بين الحسابين.

## 🔄 مسار عمل النظام (Workflow)

```
[1. قسم الدراسات العليا]
       │  يملأ: اسم الطالب الرباعي، النفقة، القسم، نوع الدراسة، التخصص، سنة القبول والتخرج
       ▼
[تخزين ومزامنة فورية] ───> [Google Sheet سحابياً]
       │
       ▼
[2. قسم الحسابات]
       │  يختار الطالب من قائمة الانتظار (البيانات الأكاديمية معروضة ومقفلة)
       │  يرفع: صورة الوصل + يحدد المبلغ + تاريخ التسديد + اسم المدقق
       ▼
[3. قسم الدراسات العليا]
       │  يستعرض السجل المحدث مع صورة الوصل واسم المدقق
       │  ينزل استمارة براءة الذمة أو الكشف العام بصيغة PDF
```

## 🚀 طريقة التشغيل

### الطريقة الأولى: التشغيل المباشر في المتصفح
فقط افتح ملف `index.html` في أي متصفح إنترنت (مثل Chrome أو Edge أو Firefox) بالنقر المزدوج عليه.

### الطريقة الثانية: عبر خادم بايثون المحلي
افتح موجه الأوامر (Terminal / PowerShell) في مجلد المشروع واكتب:
```bash
python server.py
```
سيفتح النظام تلقائياً على الرابط: `http://localhost:8000/index.html`.

## 📊 الربط المباشر مع Google Sheets

جدول البيانات المعتمد للنظام:
`https://docs.google.com/spreadsheets/d/1U6qpwnVtTDf-K7OpwNWtI-seN7bN2GaDwfYT2m2SL60/edit?usp=sharing`
معرف الجدول (Spreadsheet ID): `1U6qpwnVtTDf-K7OpwNWtI-seN7bN2GaDwfYT2m2SL60`

### خطوات خزن البيانات الحالية والتفعيل التلقائي (Google Apps Script):
1. افتح جدول Google Sheet المذكور أعلاه في حسابك:
   `https://docs.google.com/spreadsheets/d/1U6qpwnVtTDf-K7OpwNWtI-seN7bN2GaDwfYT2m2SL60/edit?usp=sharing`
2. من القائمة العلوية اضغط على: **ملحقات (Extensions) -> Apps Script**.
3. الصق الكود الموجود في ملف `GoogleAppsScript.js` كاملاً واضغط على زر **حفظ**.
4. **لخزن بيانات الطلاب والتسديدات الحالية فوراً:** اختر دالة `populateInitialData` من شريط الأدوات العلوي واضغط **تشغيل (Run)**. ستتم تعبئة كافة بيانات الطلاب والتسديدات والمدققين في الجدول مباشرة!
5. **للتحديث التلقائي المستمر:** اضغط على **نشر (Deploy) -> نشر جديد** كـ **تطبيق ويب (Web app)** واجعل الوصول: **Anyone**، وسيتم حفظ أي طالب أو وصل جديد يضاف في الواجهة تلقائياً.

> كما تم تجهيز ملف `بيانات_الطلبة_والتسديدات.csv` في مجلد المشروع والذي يمكن استيراده مباشرة إلى Google Sheet عبر: **ملف -> استيراد -> تحميل**.

## 📄 ميزات ملفات الـ PDF والتصدير

- **استمارة براءة ذمة وتسديد مالي فردية:** تقرير رسمي لكل طالب يحتوي على الترويسة الأكاديمية، كافة البيانات الأكاديمية والمالية، صورة الوصل الأصلي، واسم المدقق وختم التدقيق.
- **كشف تسديدات شامل:** جدول كامل بجميع الطلبة مع إجماليات المبالغ وحالة التسديد.
- **تصدير Excel:** زر تصدير مباشر لملف `.xlsx` متوافق تماماً مع Google Sheets و Excel.
